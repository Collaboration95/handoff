EVENT DECISION — HACKATHON VS ASTRA COMMONS

DECISION
Attend the Agents Everywhere hackathon.

WHY
The alternative event, Astra Commons Singapore, offers:
- casual networking
- GPT-6 Astra / Codex discussion
- approximately $100 Codex credits + $50 API credits for eligible registered attendees

That is strong guaranteed value, but the hackathon has much higher career and portfolio upside.

HACKATHON UPSIDE
Even without winning:
- working public project
- GitHub repo
- demo video
- judge feedback
- strong interview story
- portfolio piece
- concrete example of agentic software engineering

If placed:
- Singapore regional placement becomes a strong resume / LinkedIn / interview credential
- potential prize / credits
- global submission exposure

WHY THIS PARTICULAR HACKATHON IS A GOOD FIT
The Relay concept naturally matches:
- realtime agents
- live collaboration
- voice
- tools
- approvals
- context-aware actions

This is better than trying to force an unrelated idea into the prompt.

CAREER INTERPRETATION
For a master's student in Software Engineering:
- $150 in credits is useful but replaceable.
- A strong shipped system and possible hackathon placement is less replaceable.
- A concrete working project makes future networking conversations stronger.

KEY DECISION PRINCIPLE
Take the higher-upside opportunity because a credible MVP idea already exists and can realistically be completed solo.

AFTER THE HACKATHON
If Relay works well:
- reuse it for future Astra / Codex meetups
- demo it to builders
- improve it into a portfolio project
- potentially turn the hackathon demo into a more production-like meeting agent

NETWORKING LINE
"I built a realtime meeting agent that listens to live discussion and turns decisions directly into GitHub and Slack actions."
